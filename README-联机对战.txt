                    飞机大战 - 多人联机对战使用说明
================================================================================

问题诊断结果：
--------------
✗ 服务器未运行（端口8080未被占用）
  这就是为什么显示"端口错误和网络错误"的原因！


立即解决方案：
--------------

步骤1：启动服务器
  双击项目根目录的 "启动服务器.bat"
  
  成功标志：
  看到以下消息：
  ═══════════════════════════════════════════════
    飞机大战联机对战服务器已启动
    端口: 8080
  ═══════════════════════════════════════════════
  
  重要：保持这个窗口运行，不要关闭！


步骤2：重新安装游戏
  在命令行运行：
  gradlew.bat installDebug


步骤3：测试创建房间
  1. 在模拟器中打开游戏
  2. 进入"多人对战"
  3. 服务器地址输入：10.0.2.2
  4. 点击"创建房间"


步骤4：查看日志（可选）
  新开一个命令行窗口：
  adb logcat -s BattleClient:D


成功标志：
----------
✓ 服务器窗口显示：[创建房间] ROOM_xxx by PlayerName
✓ 游戏界面显示：房间ID和"等待对手加入..."


常见问题：
----------

Q: 为什么显示"网络错误"？
A: 服务器没有启动。必须先运行"启动服务器.bat"

Q: 模拟器使用什么IP地址？
A: 必须使用 10.0.2.2（不是localhost）

Q: 真机使用什么IP地址？
A: 使用电脑的局域网IP（如192.168.1.100）
   查看方法：在命令行运行 ipconfig

Q: 如何测试服务器是否正常？
A: 打开浏览器访问：
   http://localhost:8080/battle/status?roomId=test&playerId=test
   应该看到JSON错误（这是正常的）


多人对战测试流程：
------------------

1. 启动服务器（双击"启动服务器.bat"）

2. 启动两个模拟器

3. 安装游戏到两个模拟器：
   gradlew.bat installDebug

4. 模拟器1：
   - 进入"多人对战"
   - 服务器地址：10.0.2.2
   - 点击"创建房间"
   - 记录房间ID

5. 模拟器2：
   - 进入"多人对战"
   - 服务器地址：10.0.2.2
   - 输入房间ID
   - 点击"加入房间"

6. 双方点击"开始对战"

7. 观察分数实时同步


重要提示：
----------
1. 服务器必须先启动才能创建房间
2. 服务器窗口必须保持运行
3. 模拟器必须使用10.0.2.2地址
4. 每次修改代码后需要重新安装游戏
